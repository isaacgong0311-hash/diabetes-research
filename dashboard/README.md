# Diabetes Research Workspace

Open `index.html` in a modern browser to use the dashboard. No installation, account, server, or API key is needed. The existing research brief and protocol are linked from the dashboard.

Add and edit sources, save notes, change review status, search and filter the library, and export/import JSON backups. The starter library contains ten sources from the existing research.

Data is stored in the browser's local storage for this particular browser and local origin. Clearing browser data, switching browsers or computers, or moving to a different origin can make it unavailable. Use **Export backup** to keep a portable copy. Import replaces the current library after confirmation.

This is a research organization tool, not a source of personalized medical advice. It does not automatically update source content or verify studies.
